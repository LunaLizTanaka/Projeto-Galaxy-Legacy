Como testar no Galaxy Tab A

  1. Abra esta página no Chrome do tablet, usando um endereço HTTPS.
  2. Toque no menu de três pontos do Chrome.
  3. Escolha Adicionar à tela inicial (o texto pode variar).
  4. Confirme o nome Galaxy Legacy e adicione o ícone.
  5. Volte à tela inicial do Android e abra o novo ícone.

O que observar

  • Se o ícone Galaxy Legacy aparece na tela inicial.
  • Se a página abre sem a barra de endereço e os controles normais do Chrome.
  • Se o botão Voltar do Android retorna corretamente.

Este é apenas um teste de instalação/abertura. Não lê o histórico do Chrome, não lista atalhos do Android, não instala APK e não oferece modo offline. Não há Service Worker nem cache offline programado.
